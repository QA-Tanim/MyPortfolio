# Portfolio Website

A personal portfolio website for Ishtiaque Ahmed Tanim, focused on software quality assurance, automation, API testing, and performance engineering.

## Project structure

- `index.html` — main page structure and content
- `styles.css` — site styling and responsive layout
- `script.js` — portfolio data, rendering logic, filtering, and interactivity
- `og-image.png` — social preview / favicon image
- `Ishtiaque_Ahmed_Tanim_SQA_Engineer.pdf` — downloadable CV

## Local preview

Open `index.html` directly in a browser, or serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This portfolio is static and does not require a build step. It is designed to showcase QA experience, projects, case studies, and contact details in a clean, modern layout.
